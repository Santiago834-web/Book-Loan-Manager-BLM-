# Book-Loan-Manager-BLM-
Este proyecto propone la implementación de un Catálogo Público en Línea OPAC para la biblioteca de la institución, con el fin de modernizar el acceso a los recursos bibliográficos físicos y digitales. Actualmente, los estudiantes presentan dificultades para consultar la disponibilidad de libros, lo que genera demoras, desorden y subutilización del material. El OPAC permitirá que cualquier usuario ingrese desde un computador o celular, busque libros por título, autor o categoría, verifique disponibilidad en tiempo real y realice solicitudes o reservas virtuales.
La biblioteca de la institución enfrenta dificultades debido a la gestión manual de consultas, préstamos y reservas de libros, lo que genera demoras, pérdida de información y limita el acceso al catálogo fuera del horario escolar. Para solucionar esta situación, se propone digitalizar y automatizar la gestión bibliográfica mediante un sistema web que permita consultar la disponibilidad de los libros en tiempo real, realizar búsquedas rápidas, gestionar préstamos y reservas de forma eficiente y acceder a la información desde cualquier lugar.
